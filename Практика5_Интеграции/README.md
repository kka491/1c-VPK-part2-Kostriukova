## Как проверить

**Обработки.** Открыть базу в режиме «1С:Предприятие», в главном меню выбрать «Файл → Открыть…» и указать файл `.epf`; на предупреждение безопасности ответить «Да».

**Базы.** Создать пустую информационную базу, открыть ее в конфигураторе и выполнить «Администрирование → Загрузить информационную базу», выбрав `.dt`. Пользователь — «Администратор», без пароля. После загрузки на новое место БСП может заблокировать работу с внешними ресурсами; чтобы обмен по расписанию работал, работу с внешними ресурсами нужно разрешить (подробнее — в отчете, п. 2.4).

**Обмен (задача 3).** В обеих базах обработка обмена уже подключена: «Настройки → Сервис → Дополнительные обработки», команда обмена выполняется по расписанию каждые 60 секунд, пока открыт клиент базы. Новые документы Филиала попадают в Головной офис, новая номенклатура Головного офиса — в Филиал. Журнал обмена: `C:\UNFExchange\log\exchange.log` или команда «Обмен Филиал - Головной офис (журнал и ручной запуск)».

**Заглушка (задача 5\*).** В Mockoon открыть `Mockoon/Test.json` («File → Open local environment») и запустить сервер. В обработке `HTTPЗапросGET.epf` выполнить GET для `http://localhost:3000/Test/` — ответ `{"testmessage": "Hello world!"}`.
